📚 Khái niệm Sắp xếp Trộn (Merge Sort)

Merge Sort (Sắp xếp trộn) là thuật toán sắp xếp sử dụng chiến lược Chia để trị (Divide and Conquer). Thuật toán hoạt động bằng cách:

1

Chia đôi

Chia danh sách thành hai nửa bằng nhau

CHIA
2

Sắp xếp đệ quy

Gọi đệ quy sắp xếp từng nửa độc lập

ĐỆ QUY
3

Trộn hai nửa

Hợp nhất hai nửa đã sắp xếp thành một

TRỘN

⚡ Tại sao Merge Sort phù hợp với Linked List?

  • Không cần mảng phụ: Chỉ thao tác trên con trỏ, không cần cấp phát mảng mới!
  • Space O(1): Trên Linked List, Merge Sort chỉ cần thay đổi con trỏ → bộ nhớ thêm là O(1)
  • Stable sort: Giữ nguyên thứ tự các phần tử bằng nhau → quan trọng cho sắp xếp đa tiêu chí
  • Chia đôi dễ dàng: Kỹ thuật con trỏ nhanh/chậm tìm giữa trong O(n) mà không cần biết độ dài trước

🐤🐇 Kỹ thuật Con trỏ Nhanh/Chậm (Fast/Slow Pointer)

Để chia đôi danh sách liên kết mà không cần đếm số phần tử trước, ta dùng hai con trỏ:

  • Con trỏ chậm 🐤 (slow): Di chuyển 1 bước mỗi lần lặp
  • Con trỏ nhanh 🐇 (fast): Di chuyển 2 bước mỗi lần lặp
  • Khi con trỏ nhanh đến cuối danh sách → con trỏ chậm đang ở vị trí giữa!

💻 Mã nguồn với giải thích

Hàm chính: sap_xep_tron()

Python def sap_xep_tron(self, tieu_chi='gia_ban'): # Danh sách rỗng hoặc 1 phần tử → không cần sắp xếp if self.head is None or self.head.next is None: return # Bước 1: Chia đôi danh sách (con trỏ nhanh/chậm) nua_dau, nua_sau = self._chia_doi() # Bước 2: Sắp xếp đệ quy từng nửa ds_nua_dau = DoublyLinkedList() ds_nua_dau.head = nua_dau ds_nua_sau = DoublyLinkedList() ds_nua_sau.head = nua_sau ds_nua_dau.sap_xep_tron(tieu_chi) # Đệ quy nửa đầu ds_nua_sau.sap_xep_tron(tieu_chi) # Đệ quy nửa sau # Bước 3: Trộn hai nửa đã sắp xếp self._tron(ds_nua_dau, ds_nua_sau, tieu_chi)

Hàm chia đôi: _chia_doi()

Python def _chia_doi(self): con_tro_cham = self.head # Di chuyển 1 bước con_tro_nhanh = self.head # Di chuyển 2 bước while con_tro_nhanh.next and con_tro_nhanh.next.next: con_tro_cham = con_tro_cham.next con_tro_nhanh = con_tro_nhanh.next.next nua_dau = self.head nua_sau = con_tro_cham.next con_tro_cham.next = None # Cắt đôi danh sách return nua_dau, nua_sau

Hàm trộn: _tron()

Python def _tron(self, ds_a, ds_b, tieu_chi): node_tam = Node(None) # Node tạm hien_tai = node_tam node_a = ds_a.head node_b = ds_b.head while node_a and node_b: gia_tri_a = self._lay_gia_tri(node_a.data, tieu_chi) gia_tri_b = self._lay_gia_tri(node_b.data, tieu_chi) if gia_tri_a <= gia_tri_b: # So sánh hai Node đầu hien_tai.next = node_a node_a.truoc = hien_tai node_a = node_a.next else: hien_tai.next = node_b node_b.truoc = hien_tai node_b = node_b.next hien_tai = hien_tai.next # Nối phần còn lại if node_a: hien_tai.next = node_a node_a.truoc = hien_tai if node_b: hien_tai.next = node_b node_b.truoc = hien_tai self.head = node_tam.next if self.head: self.head.truoc = None

📈 Phân tích độ phức tạp O(n log n)

Mỗi mức của cây đệ quy xử lý tổng cộng n phần tử. Số mức là log₂n. Do đó tổng = n × log n.
